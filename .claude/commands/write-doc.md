在项目 docs/ 目录下创建一篇文档。用户会告诉你文档主题。

**文档规范：**

1. 文件名用英文短横线命名，如 `docs/xxx-yyy.md`
2. 语言使用中文
3. 结构简洁明了，让人一看就懂，不需要长篇大论

**必须包含的结构（按需选用）：**

- **标题** — 一级标题，简短说明这是什么
- **结构图** — 用 ASCII 方框图展示架构、组件关系或层级
- **流程图** — 用 ASCII 流程图展示操作步骤或数据流向
- **表格** — 用表格整理命令、参数、选项等对照信息
- **使用方法** — 简短的代码块示例，直接可复制执行
- **原则** — 几条核心规则，bullet point 列出

**风格要求：**

- 不写废话，不写"本文档介绍了..."之类的开头
- 直接进入正题
- 图 > 表 > 文字（能用图说清的不用文字）
- 每个段落不超过 3 行
- 代码块标注语言类型

**参考模板：** docs/fork-workflow.md

用户输入：$ARGUMENTS
